# 3D Puddles (ver 2.0) for IX-Ray Platform

Addon that adds puddles to the levels

## Overview

The addon contains 3d puddles placed on the locations of the original game Call of Pripyat. Compatible with all mods and does not require adaptations

## Remarks

> [!WARNING]
>
> Supported only on __IX-Ray Platform__!

## Requirements

Installation:

1. Install original Stalker Call of Pripyat 1.6.02
2. Install current version of IX-Ray (minimum 1.1)
3. Extract addon archive into the game folder
4. Start the game and play

Link to the current __IX-Ray__ [release](https://github.com/ixray-team/ixray-1.6-stcop/releases/latest)
